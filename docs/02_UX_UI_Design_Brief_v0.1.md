# 푸르메재단 넥슨어린이재활병원 직원교육 LMS
## UX/UI Design Brief v0.1

- 작성일: 2026-10-06
- 기반 문서: 직원교육 LMS PRD v0.1
- 대상 환경: PC·가로형 태블릿 우선 반응형 웹
- 문서 상태: UX/UI 인터뷰 기반 설계 초안

---

## 1. 디자인 목표

### 1.1 핵심 경험

이 플랫폼의 학습자 경험은 ‘해야 할 교육만 처리하는 행정 시스템’보다 **직원이 교육목록을 둘러보고 필요한 과정을 발견하는 병원 교육 라이브러리**에 가깝게 설계한다.

다만 신규직원 필수교육 누락을 방지하기 위해 탐색 중심 홈 안에 필수교육 상태를 항상 확인할 수 있는 안전장치를 둔다.

> 콘텐츠 탐색의 자유로움과 필수교육 관리의 명확성을 함께 제공한다.

### 1.2 시각적 인상

- 병원 공식 브랜드가 전달하는 신뢰감
- 교육 콘텐츠가 돋보이는 차분한 화면
- 사진 중심의 큰 교육 카드
- 과도한 장식보다 명확한 위계와 넉넉한 여백
- 직원 업무도구에 적합한 안정적이고 성숙한 분위기

### 1.3 UX 원칙

1. **Continue first**: 재접속한 직원은 최근 학습을 즉시 이어간다.
2. **Browse naturally**: 부서·직종·필수여부를 기준으로 자연스럽게 탐색한다.
3. **Mandatory stays visible**: 탐색형 홈에서도 필수교육 상태는 숨겨지지 않는다.
4. **One clear next action**: 각 화면에서 다음 행동을 하나의 주 버튼으로 명확히 제시한다.
5. **Content over chrome**: 메뉴와 장식보다 영상·과정 이미지·학습 상태를 우선한다.
6. **Operational clarity**: 관리자 화면은 승인대기와 반복업무를 먼저 보여준다.

## 3. 전체 정보구조

### 3.1 전역 내비게이션

PC와 가로형 태블릿에서 **상단 메뉴 + 접히는 왼쪽 사이드바** 조합을 사용한다.

#### 상단 영역

- 병원 로고·플랫폼명
- 전체 교육 통합검색
- 관심교육
- 사용자 프로필·역할 표시
- 사이드바 열기·닫기

#### 학습자 사이드바

- 홈
- 전체 교육
- 필수교육
- 선택교육
- 최근 본 교육
- 관심교육
- 내 학습·이수내역

#### 관리자 사이드바

- 관리자 홈
- 승인관리
- 교육과정
- 회원관리
- 부서·기준정보
- 이수현황
- 엑셀·보고서
- 이수증 설정

### 3.2 반응형 원칙

- 데스크톱: 사이드바 펼침을 기본값으로 제공할 수 있다.
- 가로형 태블릿: 사이드바는 기본 접힘 상태로 시작한다.
- 세로형 태블릿: 사이드바는 오버레이 드로어로 전환한다.
- 영상 학습 화면에서 콘텐츠 영역을 확보하기 위해 사이드바는 자동으로 접힌다.

## 4. 학습자 홈

### 4.1 정보 우선순위

1. 최근 학습 이어보기
2. 필수교육 상태 요약
3. 새로 게시된 선택교육
4. 직종·직무별 교육
5. 부서별 교육
6. 최근 본 교육
7. 관심교육

### 4.2 권장 화면 구조

```text
[상단 전역 메뉴: 로고 | 통합검색 | 관심교육 | 프로필]
[접히는 사이드바]

[최근 학습 이어보기 — 대형 가로 카드]
[필수교육 상태 — 작고 명확한 상태 스트립]
[새로 등록된 교육 — 큰 이미지 카드]
[직종·직무별 교육]
[부서별 교육]
[최근 본 교육]
```

### 4.3 최근 학습 이어보기

홈에서 가장 큰 첫 영역으로 배치한다.

포함 정보:

- 대표 이미지 또는 영상 스틸
- 교육과정명
- 현재 차시
- 전체 진행률
- 마지막 학습 시점
- `이어서 학습하기` 주 버튼

과정이 여러 개이면 가장 최근 과정 1개를 크게 보여주고 나머지는 옆으로 넘기는 방식보다 하단의 작은 목록으로 제공한다. 사용자가 다음 행동을 고민하지 않도록 주 행동은 하나로 제한한다.

### 4.4 필수교육 안전장치

탐색 중심 홈이라도 다음 상태를 상단에서 확인할 수 있어야 한다.

- 미시작 필수교육 수
- 진행 중 필수교육 수
- 완료한 필수교육 수
- `필수교육 보기` 바로가기

이수기한은 없으므로 경고색이나 마감 압박 표현은 사용하지 않는다. 미이수 여부는 중립적이지만 분명하게 표시한다.

## 5. 교육 탐색과 검색

### 5.1 탐색 기준

- 필수교육·선택교육
- 직종·직무
- 부서

### 5.2 탐색 보조기능

- 전체 교육 통합검색
- 최근 본 교육
- 관심교육 저장

### 5.3 검색 경험

- 상단 검색창은 모든 학습자 화면에서 유지한다.
- 과정명, 교육소개, 부서, 직종·직무를 검색 대상으로 한다.
- 검색 결과에서 필수·선택, 직무, 부서를 추가로 좁힐 수 있다.
- 결과 없음 화면에는 검색어 수정과 전체 교육 보기 행동을 제공한다.

## 6. 교육과정 카드

### 6.1 카드 방향

- 큰 대표 이미지 중심
- 여유로운 간격
- PC 기준 3열 카드 권장
- 가로 태블릿은 화면 폭에 따라 2~3열

### 6.2 카드 필수 정보

- 대표 이미지
- 과정명
- 담당 부서
- 강사

상태가 있는 경우 이미지 위 또는 카드 하단에 다음 정보를 보조적으로 표시한다.

- 필수·선택 배지
- 신규 배지
- 관심교육 저장 버튼
- 학습 중인 과정의 진행률

### 6.3 대표 이미지 운영

사진과 제목을 함께 사용하는 자동 템플릿을 제공한다.

권장 규칙:

- 공통 이미지 비율: 16:9
- 부서가 사진을 등록하면 브랜드 색상 오버레이와 제목을 자동 적용
- 사진이 없으면 병원 공통 기본 이미지 사용
- 제목 영역의 위치·글자 수·명암 대비를 템플릿으로 제한
- 직원·환자 사진은 초상권·개인정보 확인 후 사용

개별 부서가 자유롭게 디자인한 썸네일을 그대로 올리도록 하면 품질 편차가 커질 수 있으므로 권장하지 않는다.

## 7. 교육 상세 화면

### 7.1 수강 전 핵심 정보

- 교육소개
- 학습목표
- 대상 직종
- 대상 부서

### 7.2 권장 배치

```text
[대표 이미지]
[필수/선택 배지] 과정명
[대상 직종 · 대상 부서]
[신청하기 또는 학습 시작하기]

[교육소개]
[학습목표]
[차시 구성]
```

총 교육시간, 차시 수, 이수조건 등은 수강 판단에 필요한 보조 메타데이터로 상단 요약영역에 간결하게 표시하되, 본문보다 강조하지 않는다.

### 7.3 주 버튼 상태

- 필수 배정 전: 해당 없음
- 필수 배정됨·미시작: `학습 시작하기`
- 진행 중: `이어서 학습하기`
- 선택교육 미신청: `교육 신청하기`
- 선택교육 신청 완료: `학습 시작하기`
- 이수 완료: `다시 보기`

## 8. 영상 학습 화면

### 8.1 데스크톱·가로형 태블릿 구조

- 왼쪽: 큰 Vimeo 영상
- 오른쪽: 전체 차시 목록과 완료 상태
- 영상 아래: 현재 시청률, 전체 진행률, 첨부자료

### 8.2 차시 패널

각 차시에 다음 상태를 표시한다.

- 잠김
- 학습 가능
- 학습 중
- 시청 기준 충족
- 완료

필수교육은 앞 차시의 기준을 충족해야 다음 차시가 열린다. 선택교육은 모든 차시를 자유롭게 선택할 수 있다.

### 8.3 학습 상태 표현

- 현재 영상 시청률
- 전체 과정 진행률
- 완료한 차시 수
- 평가 응시 가능 여부

진행률은 색상만으로 표시하지 않고 숫자와 상태 문구를 함께 사용한다.

### 8.4 태블릿 대응

- 가로형: 영상과 차시 패널을 나란히 유지한다.
- 폭이 부족하면 차시 패널을 접을 수 있게 한다.
- 세로형: 영상 아래에 차시 패널을 배치하거나 하단 드로어로 전환한다.
- 주요 버튼의 터치 영역은 최소 44×44px 이상으로 한다.

## 9. 첫 로그인 안내

첫 로그인 시 핵심 기능을 3단계로 안내한다.

1. **교육 찾기**: 검색과 필수·선택교육 탐색
2. **학습 이어가기**: 최근 학습과 진행률 확인
3. **이력 확인하기**: 이수내역과 이수증 확인

운영 원칙:

- 전체화면 장문 튜토리얼 대신 실제 홈 위에 짧은 안내를 표시한다.
- `건너뛰기`를 제공한다.
- 완료 후에는 도움말에서 다시 볼 수 있다.

## 10. 중앙 관리자 홈

### 10.1 최우선 정보

1. 가입 승인 대기
2. 콘텐츠 승인 대기
3. 최근 등록·수정된 교육과정
4. 회원·부서 관리 바로가기

### 10.2 권장 구성

- 상단 업무 카드: 가입 승인 대기 수, 콘텐츠 승인 대기 수
- 중앙 목록: 처리해야 할 승인 항목
- 최근 과정: 최근 등록·수정 내역
- 빠른 작업: 회원 일괄등록, 과정 만들기, 부서관리, 엑셀 내보내기

통계는 관리자 홈의 첫 목적이 아니라 별도 이수현황 화면에서 제공한다.

## 11. 과정 작성 UX

인터뷰에서 선택된 세 가지 방식을 역할에 따라 조합한다.

### 11.1 신규 과정

단계형 작성 마법사:

1. 기본정보
2. 대상·교육유형
3. 차시·Vimeo 영상
4. 첨부자료
5. 평가문항
6. 미리보기·승인 요청

각 단계는 임시저장하고, 완료되지 않은 항목을 표시한다.

### 11.2 기존 과정 수정

생성 후에는 전체 항목을 한 화면에서 빠르게 수정하는 편집모드를 제공한다.

### 11.3 반복 교육

기존 과정 또는 공통 템플릿을 복제해 제목·대상·영상·문항을 수정할 수 있다.

이 구조는 초보 담당자의 실수를 줄이면서 숙련 담당자의 작업속도도 유지한다.

## 12. 콘텐츠 승인 UX

### 12.1 화면 구조

- 왼쪽 또는 중앙: 직원에게 보이는 과정 화면 미리보기
- 오른쪽: 교육정보·차시·평가 검토 패널
- 하단 또는 고정영역: 승인 체크리스트와 승인·반려 버튼

### 12.2 승인 체크리스트 예시

- 교육과정명과 소개가 명확한가?
- 대상 직종·부서가 정확한가?
- Vimeo 영상이 정상 재생되는가?
- 차시 순서와 첨부자료가 적절한가?
- 평가문항과 정답이 정확한가?
- 환자·직원 개인정보가 포함되지 않았는가?

모든 필수 항목 확인 후에만 승인 버튼을 활성화한다.

## 13. 이수현황과 통계

### 13.1 표현 방식

요약 카드와 상세 표를 조합한다.

요약 카드 예시:

- 전체 참여 인원
- 이수 인원
- 진행 중 인원
- 미시작 인원
- 이수율

### 13.2 상세표 필터

- 교육과정
- 부서
- 상태: 이수·진행·미시작

### 13.3 일괄 작업

- 여러 직원 가입 승인
- 직원별 교육 일괄 배정
- 선택 결과 엑셀 다운로드

선택 항목 수와 적용될 작업을 명시하고, 영향이 큰 작업은 확인창을 거친다.

## 14. 시각 디자인 시스템 방향

### 14.1 색상

- 병원 공식 브랜드 색상을 핵심 색상으로 사용한다.
- 배경은 흰색과 밝은 중성색을 중심으로 구성한다.
- 브랜드 색상은 주 버튼, 진행 상태, 활성 메뉴 등 의미 있는 위치에 제한한다.
- 필수·선택·진행·완료 상태는 색상과 텍스트를 함께 사용한다.

정확한 색상값은 병원 브랜드 가이드 확인 후 확정한다.

### 14.2 타이포그래피

- 한글 가독성이 높은 산세리프 서체
- 큰 이미지 카드의 제목은 2줄 이내
- 본문 기본 크기 16px 권장
- 관리자 표는 14px까지 사용할 수 있으나 터치 대상은 충분히 크게 유지

### 14.3 형태

- 카드 모서리는 지나치게 둥글지 않은 중간 수준
- 그림자는 최소화하고 테두리·명도 차로 구획
- 아이콘은 단순한 선형 스타일로 통일
- 병원 공식성을 해칠 수 있는 과도한 그래디언트·유리효과·애니메이션은 피한다.

## 17. UX 수용 기준

1. 직원이 홈 진입 후 한 번의 선택으로 최근 학습을 재개할 수 있다.
2. 직원이 전체 교육에서 필수·선택, 직무, 부서를 기준으로 과정을 찾을 수 있다.
3. 교육카드만 보고 과정명과 담당 부서·강사를 이해할 수 있다.
4. 필수교육 상태가 탐색형 홈에서도 명확하게 노출된다.
5. 영상 학습 화면에서 차시 상태, 현재 시청률, 전체 진행률을 동시에 확인할 수 있다.
6. 가로형 태블릿에서 영상과 차시 목록을 함께 사용할 수 있다.
7. 신규 부서담당자가 단계형 마법사만으로 과정 초안을 완성할 수 있다.
8. 중앙 관리자가 홈에서 승인 대기 업무를 즉시 파악할 수 있다.
9. 관리자가 과정과 부서, 상태로 이수현황을 필터링할 수 있다.
10. 주요 상태와 오류가 색상에만 의존하지 않는다.
