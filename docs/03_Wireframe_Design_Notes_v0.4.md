## 이번 설계에서 정한 가정

1. 사이드바의 필수교육·선택교육·최근 본 교육·관심교육은 별도 화면이 아니라 '전체 교육' 화면의 필터 프리셋으로 처리.
2. 부서 교육담당자는 학습자 메뉴 + '부서 관리' 메뉴 그룹을 함께 사용. 부서 이수현황은 A-03을 재사용하고 부서 필터를 고정.
3. 필수 과정의 대상 규칙은 부서담당자가 제안하고, 중앙 관리자가 승인 시 확정.
4. 불합격 시 정답은 공개하지 않고 틀린 문항 수만 안내(운영정책 확정 필요).
5. 이수기한이 없으므로 필수교육 미이수는 경고색 없이 중립 표기.
6. 강조색 #4C6EB2(로고 파랑 기반). 공식 브랜드 가이드 수령 시 재확인.
7. 로그인 ID = 사번. 비밀번호 분실은 교육 담당자·부서담당자에게 초기화 요청 → 임시 비밀번호 → 첫 로그인 시 변경.
8. 로그인 실패 [5]회 시 [10]분 잠금, 세션 [30]분 — 수치는 보안 검토 후 확정.
9. 직원은 인사정보를 직접 수정하지 않음. 수정은 중앙 관리자가 회원관리에서 처리.
10. CSV 일괄등록 계정은 가입 승인 없이 바로 활성화·필수교육 자동 배정. 오류 행 제외 등록, 기존 사번 건너뜀.
11. 기준정보·계정은 삭제하지 않고 비활성화. 소속 인원·규칙 사용 항목은 비활성화 차단.
12. 배정 규칙: 조건 간 AND, 조건 내 OR. 규칙 변경 시 기존 직원 소급 배정 여부를 저장 때마다 선택.
13. 이수증 설정 변경은 새 발급분부터 적용. 직인 교체는 중앙 관리자만.
14. 반려 사유는 가입·콘텐츠 모두 필수, 신청자 화면에 그대로 노출.
15. 2026년 교육은 모두 필수·전 직원 대상·단일 영상 과정.
