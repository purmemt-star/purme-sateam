- 문서 버전: v0.1

## 1. 제품 개요

### 1.1 배경

병원은 현재 Vimeo를 통해 VOD 영상을 관리하고 자체 페이지에서 영상을 제공하고 있다. 그러나 기존 페이지는 Vimeo 영상 재생 기능을 중심으로 구성되어 있어 신규직원 교육 배정, 학습 진도, 평가, 이수 여부, 부서별 통계를 하나의 흐름으로 관리하기 어렵다.

각 부서에서 반복적으로 시행하는 신규직원 직무교육과 기타 부서교육을 영상 기반 교육자산으로 축적하고, 직원과 관리자가 교육의 배정부터 이수까지 추적할 수 있는 병원 내부 LMS로 재구축한다.

### 1.2 제품 정의

> 기존 Vimeo 영상 자산을 유지하면서 직원 등록·승인, 교육과정 구성·게시, 필수교육 자동 배정, 선택교육 신청, 영상 진도, 평가, 이수증, 부서별 통계를 통합 관리하는 병원 직원교육 플랫폼

Vimeo는 영상 저장·스트리밍 계층으로 유지하고, 새 LMS는 사용자·교육과정·진도·평가·이수 데이터를 관리한다.

### 1.3 핵심 가치

1. **표준화**: 부서별 신규직원 직무교육의 내용과 이수 기준을 일관되게 제공한다.
2. **자산화**: 일회성 대면교육을 재사용 가능한 VOD 교육과정으로 축적한다.
3. **가시성**: 중앙 관리자와 부서 교육담당자가 이수 현황을 한눈에 확인한다.
4. **운영 효율**: 가입 승인, 교육 배정, 평가, 이수증, 엑셀 보고를 하나의 시스템에서 처리한다.

## 2. 문제 정의

### 2.1 현재 문제

- 교육영상이 존재하지만 직원별 진도와 이수를 체계적으로 연결하기 어렵다.
- 부서별 교육자료가 담당자 개인이나 개별 채널에 흩어질 가능성이 있다.
- 신규직원이 자신에게 필요한 필수교육을 누락하거나 잘못 선택할 수 있다.
- 관리자가 교육과정별·부서별 참여 및 이수 현황을 즉시 확인하기 어렵다.
- 이수 결과를 보고하거나 증빙하기 위해 별도의 수작업이 필요하다.

### 2.2 해결할 핵심 질문

- 직원의 소속과 직무에 맞는 필수교육을 어떻게 빠짐없이 배정할 것인가?
- Vimeo 시청행동을 신뢰할 수 있는 진도 데이터로 어떻게 변환할 것인가?
- 부서가 만든 교육을 중앙 관리자가 어떻게 검토하고 표준화할 것인가?
- 관리자가 필요한 통계를 최소한의 조작으로 어떻게 확인·내보낼 것인가?

## 3. 목표와 성공 기준

### 3.1 제품 목표

- 병원 전체 신규직원이 자신의 필수 직무교육을 확인하고 이수할 수 있다.
- 부서 교육담당자가 단일 영상 또는 여러 차시로 구성된 교육과정을 작성할 수 있다.
- 중앙 관리자가 회원과 교육 콘텐츠를 승인하고 병원 전체 운영을 통제할 수 있다.
- 영상 시청률과 평가 결과를 결합해 이수 여부를 자동 판정한다.
- 과정별 참여·이수 통계를 부서 단위로 조회하고 전체 이수 내역을 엑셀로 내려받을 수 있다.

### 3.2 제안 성공지표

아래 수치는 운영 전 최종 확정한다.

| 영역 | 지표 | 1차 제안 기준 |
|---|---|---|
| 배정 정확성 | 승인된 직원에게 필수교육이 정확히 표시되는 비율 | 100% |
| 진도 신뢰성 | 실제 재생행동과 저장 진도의 일치율 | 99% 이상 |
| 이수 판정 | 진도·평가 조건에 따른 자동 판정 오류 | 0건 |
| 보고 정확성 | 화면 통계와 엑셀 데이터의 일치율 | 100% |
| 운영성 | 중앙 관리자가 개발자 개입 없이 회원·과정·승인을 처리 | 가능 |
| 사용성 | PC·태블릿에서 핵심 학습 흐름 완료 | 가능 |

## 4. 사용자와 권한

### 4.1 사용자 역할

| 역할 | 주요 목적 | 핵심 권한 |
|---|---|---|
| 직원(학습자) | 배정 또는 신청한 교육 수강·이수 | 내 과정 조회, 선택교육 신청, 영상 학습, 평가 응시, 이력·이수증 조회 |
| 부서 교육담당자 | 소속 부서의 교육 콘텐츠와 이수 현황 관리 | 과정 초안 작성·수정, 중앙 승인 요청, 소속 부서 통계 조회 |
| 중앙 관리자 | 병원 전체 회원·과정·이수 운영 | 가입 최종 승인, 콘텐츠 승인·게시, 전체 과정·부서 통계, 엑셀 출력, 기준·서식 관리 |

### 4.2 계정 기본정보

필수 저장 항목:

- 성명
- 사번
- 부서
- 입사일
- 직종
- 직급

설계 제안:

- 사번을 기본 로그인 ID로 사용한다.
- 이메일·휴대전화번호를 수집하지 않는 경우 비밀번호 재설정은 관리자 처리 방식으로 설계한다.
- 부서 변경 시 현재 소속은 변경하되 과거 이수기록에는 이수 당시 부서를 별도로 보존한다.

### 4.3 승인 흐름

1. 직원 계정은 관리자 일괄 등록 또는 직원 개별 가입으로 생성한다.
2. 개별 가입자는 부서 확인 대기 상태가 된다.
3. 부서 교육담당자가 소속을 확인한다.
4. 중앙 관리자가 최종 승인한다.
5. 승인 시 계정이 활성화되고 필수교육이 자동 배정된다.

## 5. 교육 운영 모델

### 5.1 교육 유형

| 유형 | 배정 방식 | 예시 |
|---|---|---|
| 필수 신규직원 교육 | 소속·직종 규칙에 따라 자동 배정 | 병원 공통교육, 부서 직무교육 |
| 선택교육 | 직원이 교육목록에서 직접 신청 | 직무 심화교육, 타 부서 공개교육 |

### 5.2 교육과정 구조

두 형식을 모두 지원한다.

1. **단일 과정**: Vimeo 영상 1개 + 평가 1개
2. **묶음 과정**: 여러 영상 차시 + 과정 평가 1개

권장 콘텐츠 계층:

```text
교육과정
├─ 기본정보·대상·분류
├─ 1개 이상의 차시
│  └─ Vimeo 영상
├─ 평가
└─ 이수 기준
```

### 5.3 콘텐츠 작성·승인

1. 부서 교육담당자가 과정 초안을 작성한다.
2. 과정 정보와 Vimeo 영상 링크를 등록한다.
3. 객관식 평가문항을 작성한다.
4. 중앙 관리자에게 승인 요청한다.
5. 중앙 관리자가 검토 후 승인·게시 또는 반려한다.
6. 게시된 과정만 직원에게 노출·배정된다.

과정 상태:

`초안 → 승인대기 → 게시 또는 반려 → 보관`

## 6. 학습 및 이수 규칙

### 6.1 영상 학습

- Vimeo 영상을 비공개 임베드 방식으로 재생한다.
- 시청 중단 지점을 저장하고 다음 접속 시 이어본다.
- 최초 학습 중 앞으로 건너뛰기는 허용하지 않는다.
- 최초 이수 전 재생속도 조절은 제공하지 않는다.
- 영상 완료 후에는 자유롭게 다시 볼 수 있다.
- 전 과정 공통 최소 시청률은 **80% 이상**이다.

### 6.2 진도율 계산 원칙

단순히 마지막 재생 위치를 진도율로 사용하지 않고, 실제 시청한 구간의 누적 범위를 기준으로 계산하는 방식을 권장한다.

예시:

`시청한 고유 구간의 합 ÷ 전체 영상 길이 × 100`

이를 통해 재생바 이동만으로 진도율이 올라가는 오류를 방지한다. Vimeo Player SDK로 구현 가능 범위를 기술검증 단계에서 확인해야 한다.

### 6.3 평가

- 문항 유형: 객관식 단일선택, 객관식 복수선택
- 합격 기준: **60점 이상**
- 불합격 시 즉시 재응시할 수 있다.
- 재응시 횟수는 제한하지 않는다.
- 영상 시청률 80% 이상 달성 후 평가에 응시하도록 순서를 제한한다.

### 6.4 이수 판정

다음 두 조건을 모두 충족하면 자동 이수 처리한다.

1. 영상 시청률 80% 이상
2. 평가점수 60점 이상

묶음 과정은 모든 필수 차시가 시청 기준을 충족하고 과정 평가를 통과해야 한다.

### 6.5 이수 결과

직원은 다음 정보를 확인할 수 있다.

- 과정별 이수 여부
- 전체 교육 이력
- 이수 완료 과정의 공통 서식 PDF 이수증

이수증 기본 포함 항목 제안:

- 성명
- 사번
- 소속 부서
- 교육과정명
- 교육시간
- 이수일
- 발급기관명
- 이수번호
- 기관 직인 이미지

이수번호 체계와 직인 사용 권한은 운영정책에서 별도 확정한다.

## 7. 핵심 사용자 흐름

### 7.1 직원 가입·수강 흐름

1. 일괄 등록 계정으로 로그인하거나 개별 가입을 신청한다.
2. 부서 확인과 중앙 승인을 거친다.
3. 홈에서 자동 배정된 필수교육과 신청 가능한 선택교육을 확인한다.
4. 교육 상세에서 과정 구성과 이수 기준을 확인한다.
5. 영상을 시청하고 중단 시 이어본다.
6. 시청률 80% 달성 후 평가에 응시한다.
7. 60점 이상이면 이수 처리된다.
8. 내 교육이력에서 상태를 확인하고 PDF 이수증을 발급한다.

### 7.2 콘텐츠 게시 흐름

1. 부서 교육담당자가 과정 초안을 만든다.
2. Vimeo 영상과 객관식 문항을 등록한다.
3. 중앙 승인 요청을 보낸다.
4. 중앙 관리자가 내용·대상·분류·영상·평가를 검토한다.
5. 승인 시 게시되고 필수 대상자에게 자동 배정되거나 선택교육 목록에 노출된다.

### 7.3 관리자 확인 흐름

1. 중앙 관리자가 과정별 참여·이수 현황을 조회한다.
2. 과정 선택 후 부서별 현황으로 내려간다.
3. 필요한 경우 전체 직원의 상세 이수 내역을 엑셀로 내려받는다.
4. 부서 교육담당자는 자신의 소속 부서 데이터만 조회한다.

## 9. 기능 요구사항

### 9.1 우선순위 정의

- **P0**: 정식 운영에 반드시 필요
- **P1**: 운영 효율과 완성도를 위해 필요
- **P2**: 후속 확장

| ID | 기능 | 우선순위 | 수용 기준 요약 |
|---|---|---:|---|
| AUTH-01 | 직원 개별 가입 | P0 | 필수 인사정보 입력 후 승인대기 상태 생성 |
| AUTH-02 | 직원 일괄 등록 | P0 | 정해진 CSV 양식으로 다수 계정 생성·오류행 확인 |
| AUTH-03 | 2단계 가입 승인 | P0 | 부서 확인 후 중앙 최종 승인 |
| AUTH-04 | 역할 기반 권한 | P0 | 직원·부서담당자·중앙관리자 권한 분리 |
| COURSE-01 | 단일·묶음 과정 | P0 | 1개 또는 여러 차시를 하나의 과정으로 구성 |
| COURSE-02 | Vimeo 비공개 임베드 | P0 | 승인된 도메인에서 로그인 사용자만 재생 |
| COURSE-03 | 과정 승인 워크플로우 | P0 | 초안·승인대기·게시·반려·보관 상태 지원 |
| ASSIGN-01 | 필수교육 자동 배정 | P0 | 승인 시 소속·직종 규칙에 맞춰 배정 |

## 11. 비기능 요구사항

### 11.1 지원 환경

- PC·태블릿 우선 반응형 웹
- 병원 외부 인터넷에서도 접속 가능
- 초기 전체 사용자 100명 미만
- Chrome, Edge, Samsung Internet의 최신 주요 버전 지원

### 11.2 보안

- HTTPS 필수
- 비밀번호 단방향 해시 저장
- 역할 기반 접근제어 적용
- 관리자 계정에 강화된 인증 적용 권장
- Vimeo 영상의 도메인 임베드 제한과 비공개 설정 적용
- 승인되지 않은 사용자에게 교육 콘텐츠 URL과 이수정보를 노출하지 않음
- 관리자 작업·승인·권한변경 감사로그 기록
- 로그인 반복 실패 제한 및 세션 만료 적용

### 11.3 데이터 신뢰성

- 진도, 평가, 이수 판정은 서버에서 최종 검증한다.
- 중복 응시·중복 이수기록 생성을 방지한다.
- 엑셀 출력값은 화면 통계와 동일한 기준을 사용한다.
- 삭제보다 비활성화·보관을 기본으로 하여 교육 이력을 보존한다.

### 11.4 사용성·접근성

- 터치 조작을 고려해 주요 버튼과 선택 영역을 충분히 크게 설계한다.
- 상태를 색상만으로 구분하지 않고 텍스트·아이콘을 함께 사용한다.
- 영상 자막 제공을 콘텐츠 운영 원칙으로 권장한다.
- 직원 홈에서 필수교육, 진행 중 교육, 이수교육을 즉시 구분한다.

## 15. 정식 출시 수용 기준

다음 조건을 모두 충족해야 병원 전체 정식 운영판으로 간주한다.

1. 직원 개별 가입과 관리자 일괄 등록이 모두 정상 작동한다.
2. 부서 확인 후 중앙 최종 승인 절차와 권한 제한이 작동한다.
3. 승인된 직원에게 필수교육이 규칙에 따라 자동 배정된다.
4. 직원이 선택교육을 직접 신청할 수 있다.
5. 단일·묶음 과정에서 Vimeo 영상이 PC·태블릿으로 재생된다.
6. 진도 저장, 이어보기, 80% 판정이 브라우저 재접속 후에도 유지된다.
7. 객관식 단일·복수선택 문항이 자동 채점되고 60점 기준을 적용한다.
8. 불합격자가 제한 없이 재응시할 수 있다.
9. 진도와 평가 조건 충족 시 중복 없이 자동 이수 처리된다.
10. 직원이 전체 교육 이력과 PDF 이수증을 확인할 수 있다.
11. 중앙 관리자가 과정별·부서별 현황을 확인하고 전체 이수내역을 엑셀로 출력할 수 있다.
12. 부서 교육담당자는 소속 부서 통계만 볼 수 있다.
13. 기존 Vimeo 영상과 과정 정보의 이전 결과가 검증된다.
14. 접근권한·개인정보·감사로그에 대한 운영 점검을 통과한다.
15. 실제 사용자 계정으로 PC·태블릿 운영 시나리오 테스트를 완료한다.
